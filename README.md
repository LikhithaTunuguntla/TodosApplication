# 📝 Todos Application

A simple **Todo List Application** built with **HTML, CSS, and JavaScript**, styled using **Bootstrap** and enhanced with **Font Awesome icons**.  
This project allows users to create, manage, and save tasks in a clean and responsive interface.

---

## 🚀 Features
- Add new tasks with validation (no empty tasks)
- Mark tasks as completed with checkboxes
- Delete tasks individually
- Auto-save tasks to localStorage (persistent across refreshes)
- Responsive design with Bootstrap
- Clean UI with custom CSS

---

## 📂 Project Structure
TODOSAPPLICATION/
├── task.html   # Main HTML file
├── task.css    # Custom styles
└── task.js     # JavaScript logic


---

## ⚙️ Setup & Usage
1. Clone or download this repository.
2. Open the project folder in **VS Code** or any editor.
3. Run the project:
   - Simply open `task.html` in your browser.
   - Or use **Live Server** in VS Code for auto-refresh.
